HR Analytics with Excel

Project Overview

This project focuses on analyzing simulated Human Resources (HR) data using Microsoft Excel.

It demonstrates data cleaning, data analysis, and dashboard development to explore employee-related metrics and organizational patterns.

Project Objectives

- Clean and standardize raw HR data.
- Analyze key employee-related indicators.
- Compare HR metrics across organizational departments.
- Examine employee hiring trends over time.
- Present analytical findings through an Excel dashboard.

Key Performance Indicators (KPIs)

The dashboard includes four key indicators:

- Total Number of Employees
- Average Monthly Salary
- Average Job Satisfaction
- Average Employee Performance

Dashboard Visualizations

The dashboard contains four visualizations:

- Employee Count by Department
- Average Monthly Salary by Department
- Average Job Satisfaction by Department
- Employee Hiring Trend Over Time

Tools & Techniques

- Microsoft Excel
- Data Cleaning & Standardization
- Excel Functions
- Pivot Tables
- Data Analysis
- Data Visualization
- Dashboard Development


Dataset

The dataset used in this project is simulated and created for educational and portfolio purposes.

It does not contain real employee records.

Key Deliverables

- Cleaned and structured dataset
- HR data analysis
- Excel dashboard
- PDF analytical report
